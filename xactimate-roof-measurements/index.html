Roof measurements prepared for Xactimate

TrueTrace creates roof measurement files for Xactimate workflows. We measure the property from aerial imagery, draw the roof geometry, classify edge types and prepare the file for import.

What is typically included in the ESX workflow

  • Pre-drawn roof facets
  • Pitch values
  • Ridge, rake, hip, valley and eave classifications
  • Roof areas and dimensions
  • Measurement data ready for estimating work

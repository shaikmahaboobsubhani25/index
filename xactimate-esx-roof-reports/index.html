FAQ
What is an ESX roof report?

An ESX roof report is a roof measurement deliverable packaged in the ESX file format used with Xactimate workflows. It can reduce the need to manually recreate the roof sketch and measurements.

Is the ESX file ready to import into Xactimate?

The ESX file is prepared for Xactimate import. Compatibility can depend on the Xactimate version and the receiving user’s software access.

Can I also get a PDF?

Yes. A detailed PDF can be added when you want both an import file and a visual report for review or sharing.

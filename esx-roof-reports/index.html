What is an ESX roof report?

For TrueTrace orders, the ESX deliverable is the Xactimate-compatible file containing the roof geometry and measurement data prepared from the property imagery.

Why contractors and adjusters use ESX files

An ESX file can reduce the time spent recreating roof geometry inside Xactimate. Your team can open the measured file and continue with the estimating work that depends on it.

ESX pricing

Residential roof measurement files start at $16 and commercial roof measurement files start at $25. Optional formatted PDF reports can be added.

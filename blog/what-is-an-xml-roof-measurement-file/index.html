What Is an XML Roof Measurement File?

What XML roof measurement files are used for and what to expect from the deliverable.

What XML means here

XML is one of the roof-measurement file formats available from TrueTrace for compatible estimating and claims workflows.

What stays the same

The underlying measurement task still focuses on the roof geometry requested for the property. The main difference is the output format selected for the customer workflow.

XML and a visual PDF

An XML file can be paired with a PDF when the team also needs an easy-to-read visual report.

Before ordering

Choose XML only when it matches the workflow you plan to use. If your team works in Xactimate instead, ESX may be the more relevant option.

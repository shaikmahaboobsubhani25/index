What Is an ESX Roof Report?

Understand what an ESX roof measurement deliverable is and when contractors use it.

What an ESX roof report is

An ESX roof measurement deliverable is a measurement file intended for an Xactimate-oriented estimating workflow. Instead of relying only on a visual PDF, the estimator receives the requested measurement data in ESX format.

What the measurement work can contain

A roof measurement project can include roof faces, total roof area, pitch information and linear dimensions such as ridge, hip, valley, rake and eave, depending on the property and selected report.

Why contractors request ESX

For teams already working in Xactimate, an ESX deliverable can reduce the need to recreate a roof sketch from a separate PDF. A PDF can still be useful as a visual reference.

What to verify before ordering

Confirm that ESX is the file format your estimating workflow requires and choose whether you also want the formatted PDF report.

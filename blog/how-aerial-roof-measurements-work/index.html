How Aerial Roof Measurements Work

From property address and imagery to traced roof geometry and a finished report.

Start with the property address

The address identifies the property that needs to be measured and helps locate available imagery.

Review available imagery

Aerial, satellite and where available oblique imagery can provide the visual source needed to understand roof geometry.

Trace the roof geometry

The roof footprint and facets are traced and reviewed so the requested areas and linear measurements can be prepared.

Prepare the deliverable

The customer receives the selected ESX, XML and/or PDF report for the estimating or claims workflow.

Why remote measurement helps

For busy contractors and adjusters, remote measurements can reduce the need to spend field time manually measuring every roof.

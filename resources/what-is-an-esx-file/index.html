What Is an ESX File?

A simple explanation of ESX files for contractors, adjusters and anyone using Xactimate-related estimating workflows.

What an ESX file is

An ESX file is a file format associated with Xactimate project workflows. In roof measurement services, an ESX deliverable can be used to transfer prepared roof measurement or sketch information into an Xactimate-based estimating process.

Why contractors and adjusters request ESX

When measurements are already prepared in a compatible file, the estimator can spend less time recreating roof geometry manually and more time working on the estimate or claim.

ESX vs PDF

An ESX file is intended for software workflow use, while a PDF is a visual document that can be reviewed, shared or stored with the job documentation. TrueTrace allows customers to choose ESX or XML and add a PDF where applicable.

When to choose XML instead

If your workflow uses compatible XML-based software rather than Xactimate, select XML in the TrueTrace order form.

Ordering from TrueTrace: Choose the property type, select ESX as the format and submit the job through the main order form.

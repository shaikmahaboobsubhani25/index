FAQ
What is an XML roof measurement file?

It is a structured roof-measurement file used in compatible estimating workflows, including Symbility-style processes, so roof geometry and measurements can be transferred without re-entering every value manually.

Do you provide a PDF with the XML?

A detailed PDF can be added to the XML order when you need a visual report for review, documentation or sharing.

Is XML the same as ESX?

No. ESX is associated with Xactimate workflows, while XML is used for compatible XML/Symbility workflows. Choose the format required by your estimating system.
